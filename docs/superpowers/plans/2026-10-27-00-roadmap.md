# NPAC Corporation — Roadmap de Implementação

**Spec:** `docs/spec.md`

A spec cobre vários subsistemas independentes. Cada sub-plano abaixo entrega software
funcionando e testável sozinho, e é escrito em detalhe só quando o anterior termina
(assim cada um nasce do código real, não de suposições).

| # | Plano | Entrega | Seções da spec |
|---|---|---|---|
| 01 | **Fundação** (`2026-10-27-01-fundacao.md`) | Monorepo, Postgres com RLS, login com MFA, permissões, auditoria, API de leads com regras de acesso provadas, casca do app web (login + navegação + lista de leads) | 1, 2, 3, 7 |
| 02 | CRM base | Novo lead (form), ficha do lead (notas, tarefas, timeline), tabela com filtros, pipeline/kanban, reuniões (agendar, reagendar, realizada/no-show), aba **Hoje**, tempo real | 4, 5.3–5.7 |
| 03 | Vendas, Dashboard e Relatórios | Produtos, form **Registrar venda** (parcial/parcelas → cobranças), métricas em SQL, Dashboard, **Relatórios** com filtros, CSV e cópia p/ WhatsApp | 5.2, 5.8, 5.9, 6 |
| 04 | Colaboração | Chat interno (geral + DMs) em tempo real, handoff p/ closer, link Google Agenda, Equipe, Playbook | 5.6, 5.10–5.12 |
| 05 | Admin e LGPD | Usuários/produtos/etapas, visualizador de auditoria, pedidos do titular, worker de retenção/anonimização, export por titular | 5.13, 7 |
| 06 | Migração e go-live | Import do Firebase (normaliza IDs, datas, valores), deploy Oracle Cloud São Paulo (Compose + Caddy + Cloudflare), backups testados, desligar Firebase | — |

Ordem obrigatória: 01 → 02 → 03. Depois de 02, os planos 04 e 05 são independentes entre si.
